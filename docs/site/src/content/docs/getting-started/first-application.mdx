Register OpenConnect in your host with one call. Privacy firewall is enabled by default.

```csharp
using OpenConnect.Core;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddOpenConnect(options =>
{
    options.Privacy.Enabled = true; // default-on
});

var app = builder.Build();
app.Run();
```
