---
title: Prerequisites
description: What you need before installing OpenConnect.
---

- **.NET 8 SDK** (LTS) — check `global.json` at the repository root for the pinned SDK.
- **Node 24+** — for this documentation site only (`docs/site`); not required to use the framework.
- **PostgreSQL + NATS** — only for integration scenarios (persistence/transport); unit-level first steps need neither.
- Optional: **Docker** for containerized dependencies; **.NET Aspire** workload for local observability.
