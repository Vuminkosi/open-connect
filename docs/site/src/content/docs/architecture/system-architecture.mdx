Package boundaries are strict: `OpenConnect.Abstractions` carries core interfaces and DTOs with no external dependencies; every other package depends inward.

<Mermaid
  title="Request path through gateway, firewall, agents, and persistence"

  Api --> Gateway[OpenConnect gateway]

  Firewall --> Agents[Agents<br/>MAF]

  Conv --> Providers[Configured model providers]
`} />

Dependency rule: abstractions never reference implementations; implementations register via `TryAddSingleton` patterns behind `AddOpenConnect`.
