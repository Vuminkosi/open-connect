# Browser voice fixture

`weighbridge-todo.wav` is a deterministic offline Windows SAPI voice rendering of:

> Create a Todo to check the weighbridge calibration tomorrow.

The text contains no confidential information. The fixture is generated locally for automated testing and is not a recording of a person. It is mono PCM16 WAV at 16,000 Hz and approximately 3.93 seconds long. The browser test resamples the capture through the existing client JavaScript path before sending it to the gateway.
