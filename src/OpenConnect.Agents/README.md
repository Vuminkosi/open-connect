# OpenConnect.Agents

This first slice provides a local execution handle and parent-child trace projection through `MafAgentFactory`. It does not yet invoke a Microsoft Agent Framework model or consume MAF runtime events; the installed MAF package's concrete runtime construction depends on a model/provider contract that is not defined in this repository slice. The trace is therefore generated by the local runner, not claimed to be a MAF event stream.

The package pin was verified with `dotnet package search Microsoft.Agents.AI` on 2026-11-06: `Microsoft.Agents.AI` latest reported version `1.27.0`.
